# CSP43 最后15分钟自检卡

> 从上到下逐项打勾。最后15分钟只修“确定存在”的问题，不大规模换算法。

## 一、先保护已有分数

- [ ] 每道已有分数的题都保存了稳定版本，如 `t3_80.cpp`。
- [ ] 当前编辑文件不是唯一可得分版本。
- [ ] 已确认每题提交状态和当前得分。
- [ ] 剩余提交次数足够，不用提交系统查编译错误。

## 二、所有文件统一检查

- [ ] 使用正确语言标准，所有文件本地编译通过。
- [ ] 删除 `freopen`、调试输出、随机对拍、额外提示文字。
- [ ] 没有读本地文件或写错误路径。
- [ ] 输出行数、空格、换行、精度符合题意。
- [ ] 多测试组的数据结构都正确清空。

## 三、数值与边界

- [ ] 乘法前已转 `1LL`，大乘积考虑 `__int128`。
- [ ] `INF + w` 不会溢出。
- [ ] 取模后的负数已归一化。
- [ ] 整数除法、向上取整、四舍五入/五取偶无误。
- [ ] 检查 `0/1` 下标、`l/r` 是否包含端点。
- [ ] 数组大小覆盖最大下标和哨兵位置。

## 四、算法专查

- [ ] 二分：单调性、最大true/最小true、上下界、`mid`方向正确。
- [ ] BFS：入队即标记；距离层数没有差1。
- [ ] Dijkstra：非负边；旧距离已跳过。
- [ ] 背包：0-1倒序、完全正序；初始化含义正确。
- [ ] 并查集/MST：找根后合并；检查连通性和边数。
- [ ] 拓扑：处理节点数不足时正确识别有环。
- [ ] 线段树：区间边界、lazy组合与下传正确。
- [ ] 优先队列：旧时间戳/旧版本已懒删除。
- [ ] 树递归：链状极限数据不会爆栈。

## 五、第3题大模拟专查

- [ ] 同一时刻事件优先级与题面一致。
- [ ] 新增、删除、查询分别处理，失败分支没有漏。
- [ ] 删除后相邻空闲区间正确合并。
- [ ] `first-fit/best-fit/最小编号优先`没有混淆。
- [ ] 字符串解析处理空行、空格、转义、大小写和十六进制。
- [ ] 不会实际展开指数级字符串。
- [ ] 所有对象引用在删除/更新后仍有效。

## 六、最小复测

- [ ] 每题重新跑官方样例。
- [ ] 每题至少跑一个最小输入。
- [ ] 第1、2题跑一个分界点左右的自造数据。
- [ ] 第3题跑一个重复操作/删除后再添加的自造数据。
- [ ] 第4、5题确认小数据部分分分支真的被执行。

## 七、最后决策

- [ ] 没有为了可能增加10分而冒险丢掉已有60分。
- [ ] 未提交题至少有一个能编译、对目标子任务正确的版本。
- [ ] 提交完成后再次确认系统显示的语言、文件和结果。
