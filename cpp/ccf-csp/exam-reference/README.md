# CSP43 考场提分资料

本目录针对“第1、2题较稳定，但第3～5题缺少可靠得分方法”的考生。

- `CSP43_考场提分参考手册.md`：主手册，按四小时流程、五个题位、部分分和排错组织。
- `CSP43_最后15分钟自检卡.md`：最后阶段逐项检查。
- `csp_exam_templates.cpp`：已使用 `g++ -std=c++17 -O2 -Wall -Wextra` 编译检查的常用模板库。

本次对话同时生成了 10 页 A4 打印版 PDF；仓库保存可维护的 Markdown/C++ 源文件，避免二进制版本与正文不同步。

## 使用顺序

1. 考前先读主手册的第0～6节，建立时间和部分分策略。
2. 只保留自己真正理解的模板；不要在考试中首次使用陌生高级结构。
3. 考前一天打印主手册；最后一页可单独作为自检卡。
4. 是否允许携带纸质资料，以准考证、考点通知与现场要求为准。
